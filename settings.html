Google Calendars

Add one row per calendar. Use the private “Secret address in iCal format” — in Google Calendar go to Settings and sharing → Integrate calendar → Secret address in iCal format. It looks like …/calendar/ical/…/private-…/basic.ics. Don’t use the public address (it only shows events you’ve made public). The secret URL is a password — anyone with it can read that calendar.
